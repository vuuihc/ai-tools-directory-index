# AI Tools Directory Index

A free, machine-readable dataset of 2,000+ AI tools: name, URL, category, pricing, and a one-line tagline.

Data comes from public submissions and public tool pages on [AIToolbox](https://aitoolbox.fyi/?utm_source=github&utm_medium=repo&utm_campaign=at10).

Refreshed manually, weekly. Data licensed [CC BY 4.0](LICENSE). See [DATA.md](DATA.md) for fields, filters, and known gaps.
